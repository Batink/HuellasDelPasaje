# HuellasDelPasaje

Archivo visual de los comienzos del hip hop chileno (1984-2008).

## Estructura del repositorio

```
.
├── frontend/   # React + Vite (JavaScript, CSS nativo, React Router)
└── backend/    # Pendiente: aún sin implementar
```

## Empezar

```bash
cd frontend
npm install
npm run dev
```

Más detalles (scripts, estructura, tipografía, assets) en [`frontend/README.md`](frontend/README.md).
